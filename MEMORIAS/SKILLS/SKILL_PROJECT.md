# 🚀 Skill: Visão Geral do Projeto

## 🎯 Objetivo
Manter a clareza sobre o que estamos construindo e para quem.

## 📝 Visão do Produto
Estamos desenvolvendo um **Web App Premium (PWA)** de precificação para impressão 3D. 
- **Foco:** Mobile-friendly (Otimizado para Poco X7 Pro).
- **Finalidade:** Consulta rápida de preços, orçamentos instantâneos e fechamento de vendas diárias.
- **Hospedagem:** GitHub Pages.
